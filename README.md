# COTA — 실시간 트레이딩 시그널

비트겟 USDT-M **코인 선물**과 바이낸스 **USDT 마켓**을 거래소별로 따로 스캔해 고승률 셋업만 골라 주는 모바일 우선 스캐너입니다.
토스/토스증권 스타일의 라이트 UI, 전면 한글 라벨, 종목별 가격 가독성, **연결된 비트겟 실계좌 잔고 기준** COTA 추천 레버리지를 제공합니다.

## 주요 기능

- **🏦 거래소 선택(바이낸스·비트겟) · 거래소별 독립 탐지 (v1.5.7 웹 기능, APK 재설치 불필요)**
  - **첫 화면 = 거래소 선택**: 아직 고르지 않았으면(첫 방문) 스캐너 대신 **Binance (바이낸스)** / **Bitget (비트겟)** 카드를 보여 줍니다.
    카드마다 **공식 로고**(`public/exchanges/binance.svg` · `bitget.svg`)·설명이 붙고, 고르면 `cota.exchange.v1`(localStorage)에 저장되어
    다음 방문부터는 바로 스캐너로 들어갑니다. 헤더의 **거래소 칩**을 누르거나 `설정 → 🏦 거래소` 카드에서 **언제든 전환**할 수 있습니다.
  - **거래소별 독립 탐지**: 시그널 목록·급등 탐색기·계약·캔들·시그널 이력이 거래소별로 분리됩니다(캐시 키 `exchange|symbol|tf`).
    거래소를 바꾸면 이전 거래소의 시그널·후보를 **즉시 비우고** 새 거래소 마켓만 다시 스캔합니다.
    · Bitget = USDT-M 선물 + 주식선물, `주식선물` 필터 사용
    · Binance = USDT 마켓 코인 전용(현물에 없는 `주식선물` 필터는 숨김, 법정화폐 쌍 제외)
  - **바이낸스 데이터 경로(정직한 폴백)**: ① `fapi.binance.com`(선물) → 451·CORS·네트워크 실패 시 ② `data-api.binance.vision/api/v3`(공식 현물 마켓 데이터, 지역 무관).
    화면의 **출처 배지**(`data-scan-source`)에 실제로 붙은 곳(`바이낸스 선물` / `바이낸스 현물 데이터` / `비트겟 선물`)을 그대로 표시합니다.
    현물 데이터에는 펀딩비·미결제약정이 없어 급등 탐색기의 ③ 숏스퀴즈를 **확인 불가(부분 점수)** 로 두고, 카드 펀딩은 `—`로 표시합니다(없는 값을 0으로 읽어 통과시키지 않음).
  - **자동매매는 비트겟 전용**: 바이낸스 모드에서 `자동매매` 탭을 열면 그 사실을 안내하고 **`Bitget으로 전환`** 버튼을 바로 제공합니다.
    바이낸스 시그널은 자동매매 감시·원클릭 주문 대상에서 **원천 제외**됩니다(비트겟 계좌로 다른 거래소 시그널이 주문되는 사고 방지).
  - **바이낸스 API 최적화**: 재스캔은 계약 목록 기준 `?symbols=` 배치로 받고(전 종목 24h 1.9MB 반복 요청 방지),
    현물 계약 스펙은 거래대금 상위 180종목만 `exchangeInfo?symbols=`로 받습니다(전체 18MB 회피). 펀딩비는 5분 캐시.

- **🎯 매매 스타일·프리셋 제거 · 잔고만 보고 유동 레버리지 · 자동매매 진입 문제 해결(v1.5.7)**

    설정 탭의 `매매 스타일`·`매매 성향 다시 설정`, 자동매매 화면의 `매매 스타일 → 자동매매` 카드(`적용`/`해제`)도 삭제했습니다.
    리스크·레버리지 상한·포지션 수는 `② 리스크 · 안전장치`에서 **숫자로 직접 정하고 `저장`**합니다.
  - **유동 레버리지 = 잔고 + 손절 폭 + 시그널 품질 + 거래소 최대 배율**: `recommendLeverage(signal, equity?, maxLever?)` 단일 규칙.
    청산 안전마진 `floor(80 ÷ 손절폭)` 에 잔고 구간 계수(소액 1.0 · 표준 0.85 · 중형 0.7 · 대형 0.55)를 곱하고,
    거래소 종목 `maxLever`(모르면 100x)를 넘지 않습니다. 자동매매도 고정 상한 없이(`maxLeverage: 0 = 유동`) 이 배율을 그대로 씁니다.
  - **진입이 안 되던 원인 수리** — ① 진입 조건이 `진입가 ±0.05% 터치`라 60초 감시에서 거의 걸리지 않던 것을
    **진입 구간(롱 `entry×0.992~1.005` · 숏 `entry×0.995~1.008`)** 으로 넓히고, 그보다 유리한 자리는 손익비 기준을 넘으면 진입합니다.
    ② 유효시간을 **봉 마감 시점부터** 세도록 고쳐 4H 시그널이 태어나자마자 만료되던 문제를 없앴습니다(기본 240분).
    ③ 게이트 기본값을 **최소 승률 45% · 손익비 1.2R** 로 완화하고, 예전 기본값(55%·1.5R·120분·10x)만 1회 마이그레이션합니다
    (직접 조정한 값은 유지). 전수 기대값 +0.2R 이상 기법은 승률 기준을 우회합니다.
    ④ 네이티브 감시도 같은 진입 구간·손익비 판정을 쓰고, **매 주기 `진입가 대기 중 — 현재가 X / 구간 Y~Z` 사유를 한글로 남깁니다**
    (같은 문구는 10분에 한 번). 같은 종목 보유·포지션 초과·자동 진입 꺼짐도 이유를 남깁니다.
    ⑤ 1일 손실 기준선이 0인 주기에 중복 진입 기록을 지워 중복 주문이 가능하던 문제, 원클릭 주문 레버리지가 25x로 잘리던 문제를 고쳤습니다.

- **💰 50% 반익절 · 잔고별 유동 레버리지(v1.5.6 · 매매 스타일 연동은 v1.5.7에서 제거)**
  - **50% 반익절(기본 ON)**: 목표가 진행률 **50% 이상 또는 +1.0R 이상**에 닿으면 보유 수량의 **50%를 시장가로 분할 익절**합니다.
    분할 수량이나 남은 수량이 거래소 최소 수량·최소 금액($5)을 못 채우면 주문을 건너뛰어 거절을 막고, 성공하면
    `💰 반익절 체결` 알림·로그를 남깁니다. 반익절 뒤에는 남은 절반의 **본절 보호 기준이 +0.05R로 강화**되어
    수익이 손실로 뒤집히기 전에 지킵니다. (`src/lib/autotrade.ts` · `PartialTpRule.java` 동일 규칙)
  - **실시간 잔고별 유동 추천 레버리지**: 같은 시그널이라도 계좌 잔고 구간에 따라 추천 배율이 달라집니다 —
    소액(**$100 미만**)은 최소 주문금액을 채우도록 스타일 상단 배율, 표준(**$100~$1,000**)은 기본 균형,
    중형(**$1,000~$5,000**)은 0.85배, 대형(**$5,000+**)은 0.7배로 낮춰 슬리피지·자금 소진을 줄입니다.
    어느 구간에서도 **청산 안전마진 `floor(80 ÷ 손절폭)`** 은 넘지 않습니다.
  - **공격적 매매는 레버리지 상한 없음(유동)**: 기존 25x 고정 캡을 없앴습니다. 손절 폭·승률/손익비 품질·실시간 잔고로
    계산해 **30x·50x도 추천**하며, 넘지 않는 선은 **청산 안전마진**과 **거래소 종목 최대 배율(계약 `maxLever`, 모르면 100x)** 뿐입니다.
  - **매매 스타일 완전 연동**: 온보딩·설정에서 `보수적`/`공격적`을 고르면 자동매매 설정이 그 프리셋으로 함께 맞춰집니다.
    보수적 = 리스크 1.5% · 5x 상한 · 2포지션 · 1일 손실 4.5% · 승률 52% · 1.5R / 공격적 = 리스크 4% · **상한 없음** · 4포지션 ·
    1일 손실 10% · 승률 45% · 1.2R. 둘 다 조기 손절·50% 반익절 ON. 자동매매 화면에 현재 스타일 배지, 스타일과 다른 값 목록,
    프리셋/현재 값 비교표와 **`적용`·`해제`** 버튼이 있습니다.
  - **② 리스크·안전장치 = 초안 + `저장` 버튼**: 1회 리스크·최대 포지션·1일 손실 한도·레버리지 상한·승률/손익비·감시 주기·
    유효시간·허용 종목·조기 손절·50% 반익절·자동 진입을 초안으로 편집합니다. 값을 바꾸면 `저장 안 됨` 배지와 파란 `저장`
    버튼이 켜지고, 누르면 `cota.autotrade.config.v1`과 24시간 감시(`autoTradeSync`)에 즉시 반영되며 `✓ 저장됨`을 보여줍니다.
    상단 지표(1일 손실 한도 등)와 프리셋 카드의 `현재` 값도 같은 순간에 바뀝니다. 켜짐·모의/실거래는 이 카드가 건드리지 않습니다.
  - **프리셋 `적용` / `해제`(`stylePresetActive`)**: `적용`은 프리셋 값으로 맞추고 연동합니다. `해제`는 지금 값을 그대로 둔 채
    연동만 끊어(`프리셋 해제됨 · 직접 설정`) 이후 저장한 리스크·손실 한도를 스타일이 덮어쓰지 않습니다. 프리셋이 관리하는
    항목을 프리셋과 다르게 저장해도 자동으로 직접 설정으로 전환되어 값이 지켜집니다.
  - **업그레이드 1회 정렬**: 이전 버전에서 **아직 손대지 않은 기본 설정**(리스크 1.5% · 10x · 2포지션 · 4.5% · 승률 55%)은

  진입가 대비 손절폭 상한(**1H 3.5% · 4H 4.5%**, 하한 0.3%)을 넘는 시그널은 만들지 않습니다(목표가 ≤ 0 원천 차단).
- **비트겟 앱 바로가기** — 카드·공유 모달의 `비트겟 거래`는 안드로이드 APK에서 **비트겟 앱**으로 바로 열립니다
  (앱 링크 → 커스텀 딥링크 → 비트겟 앱 실행 → 미설치 시에만 브라우저).
- **카드** — `롱 · 매수 / 숏 · 매도`, `진입가 · 목표가 · 본전(EQ) · 손절가`, `손익비 1 : n`, `최근 승률`,
  천단위 콤마 가격, 목표·진입·손절 가격 라벨이 붙은 미니 캔들 차트, 진행률, `발송 11. 21. 09:00` 시그널 발송 시각.
- **실전 주문 콕핏** — 카드마다 **내 시드·리스크 기준 주문 수량**을 자동 계산합니다.
  - `수량 = (시드 × 리스크%) ÷ |진입가 − 손절가|` → `주문 수량 · 필요 증거금 · 손절 도달 시 · 목표 도달 시` 4칸
  - 기본 리스크는 **1.5%**(v1.5.7 — 성향 폐지), 설정 `💼 내 매매 기준 → 실전 주문 리스크`에서 1/2/3/5/10/20/30/50% 또는 직접 입력
  - 비트겟 계약 정보(`minTradeNum` · `volumePlace` · `minTradeUSDT`)를 받아 **주문 가능한 수량으로 내림**하고,
    최소 수량·최소 금액 미만이면 경고합니다(내림이라 손실은 계획을 넘지 않음)
  - `진입가` · `수량` 원클릭 복사 → 비트겟 앱 주문 화면에 그대로 붙여넣기

  우측 가격 라벨을 함께 그립니다. 라벨이 겹치면 자동으로 위아래로 벌려 읽히게 합니다.

  보여 주고, 내 시드 기준 `평가손익 +$321 / -$157`도 함께 표시합니다. 목표·손절 시나리오는
  실전 주문 콕핏의 `목표 도달 시 / 손절 도달 시`로 현재 손익과 섞이지 않게 구분합니다.

  로고로 맞추고, 로고가 없는 신규 밈코인·주식선물은 토스 스타일 글자 아바타로 깔끔하게 폴백합니다(깨진 이미지 0건).

  엽니다. 카드 본문 탭(공유 카드 모달)과 분리되어 있어 시그널을 보다가 바로 거래 화면으로 넘어갈 수 있습니다.

  - 카드에 `COTA 추천 Nx` 배지 + 내 시드 기준 **예상 수익(+)·손절 손실(-)** 표시
  - 레버리지 선택: `COTA 추천`(기본) 또는 `5x · 10x · 20x · 50x` 고정

## 데이터

- 비트겟 공개 API: `GET /api/v2/mix/market/contracts|tickers|candles|current-fund-rate|open-interest?productType=USDT-FUTURES`
  (tickers의 `holdingAmount` = 미결제약정 수량 → USD 환산. OI 과거 시계열 API가 없어 변동률은 COTA가 관측한 직전 기록 대비)
- 업비트 `GET /v1/ticker|/v1/market/all` · 빗썸 `GET /public/ticker/ALL_KRW` · 환율 `open.er-api.com` ·
  공포·탐욕 `api.alternative.me/fng` — 모두 브라우저 CORS 통과를 헤드리스 Chromium으로 확인한 엔드포인트입니다.
- 1H/4H 200봉 실데이터를 최근 60봉 기준으로 백테스트해 승률·손익비 미달 전략은 즉시 교체합니다.
- 매매법 자체는 `npm run bench:strategies` 로 실제 비트겟 60개 마켓 500봉을 전수 백테스트해 채택/제거합니다.

## 주의

COTA는 비트겟 공개 시세를 계산해 과거 통계를 보여주는 **정보 도구**입니다. 투자 권유가 아니며,
표시된 승률·수익률은 과거 데이터 기준으로 미래 성과를 보장하지 않습니다. 레버리지 거래는 원금 전액을
잃을 수 있습니다. 카드의 주문 수량·예상 손익은 연결된 실계좌 잔고(총 자산)와 1회 리스크 %로 계산한 계획값이며,
급격한 변동·슬리피지·펀딩비로 실제 결과는 달라질 수 있습니다.
